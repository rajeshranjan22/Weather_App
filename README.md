# 🌦️ Weather App

A responsive weather application built with **React** that allows users to search for any city and get real-time weather details including temperature, humidity, pressure, and wind speed.

## ✨ Features

* 🌍 Search weather by city name
* 🌡️ Current temperature display
* 📊 Min & Max temperature
* 💧 Humidity information
* 🌬️ Wind speed details
* 📈 Pressure data
* ☁️ Weather condition (Clear, Rainy, Cloudy, etc.)
* 📱 Fully responsive design

---

## 🛠️ Tech Stack

* **React.js**
* **CSS3**
* **React Icons**
* **Weather API (OpenWeatherMap or similar)**

## ⚙️ Installation & Setup

Follow these steps to run the project locally:

```bash
# Clone the repository
git clone https://github.com/rajeshranjan22/Weather_App.git

# Navigate into the project folder
cd Weather_App

# Install dependencies
npm install

# Start the development server
npm start
```

---

## 📌 Usage

1. Enter a city name in the search bar
2. Press enter or click search
3. View real-time weather details
